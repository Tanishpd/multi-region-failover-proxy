# The constraint is that every one of these installs from a prebuilt wheel on

# proxy/requirements.txt so the unit suite exercises the same library
# behaviour the container does. (ADR-015)

# The unit tests import the real proxy app rather than a stand-in: testing a
# reimplementation of the failover loop would prove nothing about the one that
# ships.
